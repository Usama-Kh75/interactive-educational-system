# النظام التعليمي التفاعلي (Interactive Educational System) 📚🎓
### **الإصدار:** `v2.1.0`
### **إعداد وتطوير:** **المهندس أسامة خليل هاشم**

---

## 🌟 نبذة عن النظام
منظومة تعليمية متكاملة وتفاعلية مصممة لدعم الطلاب في استعراض ومذاكرة المناهج الدراسية الرسمية مع التوثيق المباشر من صفحات الكتاب الأصلي، والاستماع للنصوص المقررة بنطق إنجليزي فصيح، ومراجعة بنك القواعد اللغوية، واستشارة المعلم الذكي الموثق، وحل الاختبارات الفورية.

النظام مصمم ليعمل **محلياً ومستقلاً 100% (Offline-First)** دون الحاجة لأي برمجيات معقدة، مع إمكانية الربط التلقائي بخادم الذكاء الاصطناعي المحلي (FastAPI + Google Gemini).

## ✨ المميزات الرئيسية للنظام (v2.1.0)

### 1. 📖 عرض وهيكلة المنهج الدراسي
* **تغطية شاملة لمنهج اللغة الإنجليزية للصف الثاني متوسط (English for Iraq):**
  * **10 وحدات وفصول رئيسية** مقسمة ومفهرسة بعناية.
  * **53 درساً تفاعلياً** يضم كافة مواضيع الكتاب (مجلة المدرسة، نمط الحياة الصحي، الرياضة، وسائل الاتصال، المهن، البيئة، نصوص الاستماع، ومرجع القواعد).
  * ربط كل مقطع برقم الصفحة الأصلية في كتاب الطالب المعتمد لوزارة التربية.

### 2. 🔊 القراءة الصوتية المسموعة (Text-to-Speech)
* قارئ نصوص صوتي ذكي مدمج يعمل مباشرة عبر المتصفح:
  * نطق إنجليزي طبيعي وصحيح لمخارج الكلمات والجمل.
  * أزرار تحكم كاملة: تشغيل (`Play`)، إيقاف مؤقت (`Pause`)، واستئناف (`Resume`)، وإيقاف (`Stop`).
  * **التحكم بسرعة القراءة:** بطيء (0.8x) لمساعدة الطلاب المبتدئين، عادي (1.0x)، وسريع (1.2x).
  * **تظليل حي متزامن:** تظليل المقطع الذي يقرأه النظام لحظة بلحظة لمتابعة الكلمات بالعين والأذن.
  * زر استماع مخصص بجانب كل فقرة أو مثال لسهولة التكرار والحفظ.

### 3. 💡 بنك القواعد واللغويات المهمة (Grammar & Functions)
* تبويب مستقل ومفصل يضم **11 قاعدة نحوية ولغوية شاملة** وفق مرجع كتاب الطالب (صفحات 110-120):
  1. **s التملك (Possessive 's'):** للمفرد والجمع العادي والشاذ (ص 4 و 110).
  2. **المضارع التام مع For و Since:** التفرقة الدقيقة بين نقطة البداية والمدة الزمنية (ص 7 و 110).
  3. **التعبير عن الإعجاب وعدم الإعجاب:** أفعال المشاعر `like / love / enjoy / hate / dislike + ing` (ص 7 و 111).
  4. **وصف الأشخاص بجمل الوصل:** استخدام ضمير الوصل `who` (ص 7 و 111).
  5. **تقديم النصائح:** صيغ `should / shouldn't + مصدر` (ص 8 و 17 و 112).
  6. **أفعال الرياضات:** التمييز بين `play` لرياضات الكرة، و `go` للمنتهية بـ `-ing`، و `do` للفنون القتالية (ص 32 و 114).
  7. **الاعتياد في الماضي:** قاعدة `used to` ونفيها وسؤالها (ص 36 و 114).
  8. **المبني للمجهول (Passive Voice):** المضارع والماضي وصيغة `can be + p.p` (ص 51 و 115).
  9. **المستقبل المخطط له:** صيغة `be going to + infinitive` (ص 63 و 118).
  10. **الإلزام والقوانين مقابل النصيحة:** الفرق بين `must` و `should` (ص 74 و 119).
  11. **الاحتمالية والترجيح:** صيغ `may` و `might` (ص 77 و 119).
* يتضمن كل موضوع: الصيغة النحوية، الشرح بالعربية، أمثلة نصية منطوقة، و **تمرين سريع تفاعلي** مع تصحيح فوري وشرح للحل.

### 4. 🤖 المعلم والمساعد الذكي الموثق (AI Tutor)
* مساعد تفاعلي يجيب عن أي استفسار يخص المنهج:
  * دعم الإجابة الفورية الموثقة برقم الصفحة والمقطع.
  * يعمل بمحرك محلي حتى بدون اتصال بالإنترنت أو مفاتيح خارجية.
  * دعم اختياري لمفتاح Google Gemini API لتوليد شروحات معمقة.
  * رقائق أسئلة مقترحة سريعة بنقرة واحدة بحسب الدرس المفتوح.
  * إمكانية الاستماع لنص إجابة المعلم صوتياً بنقرة زر.

### 5. ✍️ الاختبارات والتقييم اللحظي
* توليد أسئلة تدريبية واختبارات قياس الفهم مع تصحيح لحظي، احتساب النسبة المئوية، وعرض التفسير التعليمي لكل خيار.

### 6. 📱 تطبيق ويب تقدمي قابل للتثبيت (PWA - Progressive Web App)
* **تثبيت بنقرة واحدة:** زر مدمج `📲 تثبيت التطبيق` لتثبيت المنظومة كبرنامج مستقل على سطح المكتب (Windows / Mac) أو الهاتف (Android / iOS).
* **ملف تعريف التطبيق (`manifest.json`):** أيقونات عالية الدقة وألوان مخصصة وهوية بصرية كاملة.
* **العمل أوفلاين التام (`sw.js`):** يدير Service Worker كاش الموارد ليعمل التطبيق بدون أي انقطاع وبدون اتصال بالشبكة.

## 🛠️ متطلبات التشغيل وكيفية الاستخدام

### الخيار 1: التشغيل المباشر السريع (Offline - متصفح فقط)
1. افتح ملف `index.html` مباشرة باستخدام أي متصفح حديث (Google Chrome، Microsoft Edge، Firefox).
2. سيعمل النظام بكامل مميزاته (عرض المنهج، القراءة الصوتية، القواعد، المعلم المحلي، والاختبارات) فوراً!

### الخيار 2: التشغيل المتكامل عبر الخادم المحلي (Backend API)
لتفعيل معالجة رفع المناهج الجديدة وربط الذكاء الاصطناعي السحابي:

1. **تثبيت المتطلبات:**
   ```bash
   pip install -r backend/requirements.txt
   ```
2. **تشغيل الخادم:**
   ```bash
   python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
   ```
3. افتح الرابط في المتصفح:
   ```text
   http://127.0.0.1:8000
   ```
