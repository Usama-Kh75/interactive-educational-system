# النظام التعليمي التفاعلي الشامل (Comprehensive Interactive Educational System) 📚🎓
### **الإصدار:** `v3.3.1`
### **إعداد وتطوير:** **المهندس أسامة خليل هاشم**
### **المناهج المعتمدة:**
1. **اللغة الإنجليزية:** الصف الثاني المتوسط (English for Iraq - 2nd Intermediate)
2. **اللغة العربية (المقرر الشامل):** الصف الثاني المتوسط (يتفرع إلى كتاب الجزء الأول وكتاب الجزء الثاني - وزارة التربية العراقية)

---

## 🌟 نبذة عن المشروع
منظومة تعليمية متكاملة وتفاعلية تعتمد على أحدث تقنيات الويب وتعمل بصيغة تطبيق ويب تقدمي (**Progressive Web App - PWA**) كامل الجاهزية أوفلاين 100% ومحلياً وسحابياً عبر منصة GitHub Pages.
تتميز المنظومة بدعم متكامل للمناهج الدراسية مع نصوص مشكولة وموثقة، وعرض مباشر لصفحات الكتب المعتمدة بدقة عالية، وقراءة صوتية ذكية ثنائية اللغة (عربي / إنجليزي)، وبنك شامل للقواعد والنحو، ومساعد ذكي محلي.

## ✨ المميزات الرئيسية للنظام (v3.3.0)

### 1. 📖 تكامل مناهج اللغة العربية (الجزء الأول والجزء الثاني) للصف الثاني المتوسط
- **إدراج منهجي كامل للمقرر الوزاري:**
  - **اللغة العربية - الجزء الأول (الصفحات 1 إلى 136):** 10 وحدات دراسية (رعاية الله ووعده، الإخاء، الطموح وعلو الهمة، المرء يخلد بعلمه وعمله، نحن وعلوم العربية، أمجادنا وحضارتنا، من عجائب عالم الحيوان، النهر والحياة، أحباب الله، معجم الطالب) تضم 40 درساً متكاملاً تشمل نصوص المطالعة والنصوص القرآنية والشعرية، والقواعد النحوية والإملائية، والتعبير الشفهي والتحريري.
  - **اللغة العربية - الجزء الثاني (الصفحات 1 إلى 136):** 10 وحدات دراسية (فداء لوطني، هل جزاء الإحسان إلا الإحسان، نساء في القمة، الربيع، كنوز العلم، إرادة الحياة، جمال بلادي، نور من السماء، الغرس الطيب، معجم الطالب) تضم 40 درساً شاملاً لنصوص الأدب والمطالعة، وشروحات القواعد والإملاء، والتطبيقات اللغوية.
- **استخراج ومعالجة نصوص دقيقة بالحركات التشكيلية:** الحفاظ الكامل على الحركات وعلامات الضبط بالشكل لتيسير القراءة السليمة وضبط النطق.
- **مجلدات صور مستقلة ومفهرسة:** تضمين 272 صفحة مرسومة بدقة عالية (130 DPI) عبر مسارات منظمة (`book_images/arabic_p1/page_{N}.jpeg` و `book_images/arabic_p2/page_{N}.jpeg`).

### 2. 📚 خطة منهاج اللغة الإنجليزية (English for Iraq - 2nd Intermediate)
- **الوحدات من 1 إلى 8 كاملة:** تغطية 76 درساً شاملاً من مجلة المدرسة وحتى المراجعة الشاملة النهائية مع بنك القواعد الإنجليزية (43 قاعدة) والامتحان الوزاري النهائي الشامل (100 درجة).
- **نصوص الاستماع والمحادثة:** الصفحات 90 إلى 109.

### 3. 🎨 المعرض البصري وتصفح صفحات الكتب (Visual Enrichment & Lightbox)
- **تصفح عالي الجودة لصفحات الكتب المعتمدة:** دعم التصفح والتكبير الذكي لصفحات الكتب الأصلية (كتاب اللغة الإنجليزية، وكتابي اللغة العربية بجزأيهما الأول والثاني).
- **عارض ومكبر الصور (Lightbox Modal):** تكبير صفحات الكتاب بدقة فائقة مع إمكانية تشغيل القراءة الصوتية أثناء مطالعة الصفحة ومزامنة العرض حسب المنهج المختار.
- **بطاقات المفاهيم والرسوم التوضيحية (`TOPIC_CARDS`):** بطاقات ملونة مصممة بذوق رفيع تلخص المفردات، شروحات القواعد، والأفكار المركزية لكل موضوع.

### 4. 🔊 القارئ الصوتي التفاعلي ثنائي اللغة (Bilingual Text-to-Speech)
- استماع صوتي مسموع لنصوص الدروس ومقاطع القراءة بلكنة إنجليزية طبيعية للإنجليزية، ونطق عربي سليم مع الحركات عبر محرك Web Speech API (`ar-SA`).
- تحكم فوري بالتشغيل، الإيقاف المؤقت، وتغيير السرعة (0.75x، 1x، 1.25x).
- مشغل صوتي عائم ماستر مع شاشة القراءة المباشرة (Teleprompter Tracking) لتتبع الكلمات أثناء النطق.

### 5. 💡 بنك القواعد الشامل (Grammar & Morphology Bank)
- **بنك قواعد اللغة العربية (18 قاعدة تخصصية مدمجة):**
  - **الجزء الأول:** علامات الإعراب الأصلية والفرعية، جمع المذكر السالم وملحقاته، جمع المؤنث السالم وملحقاته، المثنى وملحقاته، الأسماء الخمسة، الأفعال الخمسة، حركة الهمزة المتوسطة، والخط والترقيم.
  - **الجزء الثاني:** الفاعل، المفعول به، المفعول المطلق، المفعول فيه (ظرفا الزمان والمكان)، الاستثناء بإلا، النعت (الصفة)، العطف، الهمزة المتطرفة، والألف اللينة.
  - كل قاعدة مزودة بالصيغة الإعرابية، الشرح المبسط، الأمثلة والشواهد القرآنية والأدبية، مع أسئلة تفاعلية فورية.
- **بنك قواعد اللغة الإنجليزية (43 قاعدة متكاملة):** تغطية الأزمنة، المقارنة والتفضيل، أفعال الرغبة، المبني للمجهول، علامات الترقيم، وقواعد الكورسين الأول والثاني.
- **زر تبديل ذكي (Filter / Switcher):** إمكانية التبديل بسلاسة بين قواعد اللغة الإنجليزية وقواعد اللغة العربية بضغطة زر واحدة.

### 6. ⚡ نظام الاختبارات الذكية الفورية
- توليد اختبارات تدريبية فورية ومخصصة من نصوص الدرس والوحدة المفتوحة حالياً.
- فحص الإجابات لحظياً مع إظهار النتيجة وتفسير الإجابة الصحيحة ورقم الصفحة في الكتاب الوزاري.

### 7. 🤖 المساعد التعليمي الذكي المحلي (Local AI Tutor)
- محرك استجابة محلي ذكي يستوعب أسئلة الطالب باللغتين العربية والإنجليزية.
- يوثق الإجابات بأرقام الصفحات وأسماء الوحدات، ويدعم القراءة الصوتية للإجابة، مع شرائح مقترحة ذكية تتكيف مع المنهج والدرس الحالي.

### 8. 📲 الجاهزية للعمل بدون إنترنت 100% كـ PWA
- التطبيق قابل للتثبيت كبرنامج وتطبيق أصلي على جميع المنصات (Windows / Mac / Android / iOS).
- حفظ واسترجاع سريع لكافة الملفات والصور والنصوص من خلال Service Worker محلي آمن ومنعزل.

## 🛠️ البنية التقنية (Tech Stack)
- **الواجهة الأمامية:** Vanilla HTML5, Modern CSS3 (Variables, Flexbox, CSS Grid), Pure ES6+ JavaScript.
- **إدارة الحالات والبيانات:** LocalStorage & Service Worker Caching (`Cache-First with Network Revalidate`).
- **المعالجة واستخراج البيانات:** Python (PyMuPDF - Fitz) لتحويل صفحات الكتب واستخراج النصوص المشكولة.
- **الصوت:** Web Speech Synthesis API ثنائي اللغة.
- **الاستضافة والنشر:** GitHub Pages & Git.
