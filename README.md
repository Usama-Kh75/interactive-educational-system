### 2. 🎨 المعرض البصري وبطاقات المفاهيم المصورة (Visual Enrichment)
- **صور صفحات الكتاب المعتمدة:** عرض الصفحة الأصلية بجودة فائقة مطابقة لرقم الصفحة (`book_images/page_{N}.jpeg`).
- **عارض ومكبر الصور (Lightbox Modal):** تكبير صفحات الكتاب بدقة عالية مع إمكانية تشغيل القراءة الصوتية أثناء مطالعة الصفحة.
- **بطاقات المفاهيم والرسوم التوضيحية (`window.TOPIC_CARDS`):** بطاقات ملونة مصممة بذوق رفيع لكل درس، تتضمن أيقونات معبرة، وشرح المفردات الإنجليزية والعربية، وصناديق تركيز القواعد بالأمثلة المعتمدة (تغطي 76 بطاقة مفاهيمية لجميع وحدات المنهج من 1 إلى 8).

### 3. 🔊 القارئ الصوتي التفاعلي المسموع (Text-to-Speech)
- استماع مسموع لنصوص الدروس ومقاطع القراءة بلكنة إنجليزية طبيعية عبر محرك Web Speech API.
- تحكم فوري بالتشغيل، الإيقاف المؤقت، وتغيير السرعة (0.75x، 1x، 1.25x).
- إبراز بصري حي وتلوين الكلمات المفتاحية والقواعد النحوية داخل النص.

### 4. 💡 بنك القواعد واللغويات المهمة (Grammar & Functions Bank)
- 43 قاعدة لغوية ونحوية تفصيلية (منها قواعد الأزمنة وقواعد نبرات الصوت Intonation وتنظيم الفقرات والمبني للمجهول والمستقبل بـ be going to و when والمهارات بـ good at وضمائر الوصل who والالتزام بـ have to وقواعد should/must و may/might والنهي والاتفاق والاختلاف، وتدوين الملاحظات، والقراءة التعبيرية، وجمل الموضوع، وعلامات الترقيم الشاملة، وخلاصة الفصل الثاني) مرتبة تسلسلياً حسب الوحدات الدراسية.
- فواصل بصرية وشارات إحصائية منظمة لكل وحدة دراسية تتيح للطالب استيعاب القواعد بانتظام تسلسلي متتابع.
- كل قاعدة تتضمن: العنوان، الصفحة، المستوى، الصيغة الرياضية (Formula)، الشرح الدقيق بالعربية، أمثلة توضيحية ثنائية اللغة مع نطق صوتي مسموع، واختباراً تفاعلياً مصغراً مع التصحيح الفوري والشرح.
- فلترة سريعة للقواعد بحسب الوحدة المختارة (الوحدات 1، 2، 3، 4، 5، 6، 7، 8)، أو فلتر مخصص للأزمنة ⏱️ (Tenses)، أو البحث الفوري بالكلمة المفتاحية.

### 5. ⚡ نظام الاختبارات الذكية ونماذج الامتحانات الوزارية (Interactive & Ministerial Exams)
- توليد اختبارات فورية مكونة من 3 إلى 6 أسئلة خيارات متعددة مستخرجة بدقة من الدرس المختار حالياً.
- **الامتحان الوزاري النهائي الشامل (100 درجة):** نموذج امتحاني وزاري كامل بنظام 100 درجة يغطي مقررات الكورس الثاني كاملة (الوحدات 5 إلى 8) مع القطعة الخارجية، قطع ونصوص الكتاب، القواعد والوظائف اللغوية، المفردات والإملاء والتنقيط، والإنشاء والتعبير الكتابي مع الحلول النموذجية وتوزيع الدرجات وإمكانية الطباعة.
- أسئلة مخصصة وشاملة لجميع دروس الوحدات من الأولى إلى الثامنة.
- حساب النتائج اللحظي وتقديم شروحات توضيحية لكل إجابة موثقة بأرقام صفحات الكتاب.

### 6. 🤖 المساعد التعليمي الذكي المحلي (Local AI Educational Engine)
- محرك استجابة ذكي مبني وموثق بالكامل على نصوص وصفحات المنهج الدراسي.
- يجيب بدقة واحترافية على استفسارات الطالب مع توثيق رقم الصفحة واسم الموضوع وقراءة الإجابة صوتياً.
- شرائح أسئلة مقترحة ديناميكية تتكيف تلقائياً بحسب الدرس المفتوح.

### 7. 📲 جاهزية PWA والعمل بدون إنترنت 100%
- التطبيق قابل للتثبيت كبرنامج أصلي على الهواتف (Android / iOS) وأجهزة سطح المكتب (Windows / Mac / Linux).
- يخزن كافة الموارد والصفحات محلياً ليعمل بدون الحاجة لأي اتصال بالإنترنت أو خوادم وسيطة.

## 🛠️ البنية التقنية (Tech Stack)
- **الواجهة الأمامية:** Vanilla HTML5, Modern CSS3 (Variables, Flexbox, CSS Grid), Pure ES6+ JavaScript.
- **إدارة الحالات والبيانات:** LocalStorage & Service Worker Caching (`Cache-First with Network Revalidate`).
- **الصوت:** Web Speech Synthesis API.
- **الاستضافة والنشر:** GitHub Pages & Git.
